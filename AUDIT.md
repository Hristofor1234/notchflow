## Вердикт

Приложение сделано аккуратно и для личного инструмента — выше среднего: настройки не теряются, есть откат, контрольные суммы, самопроверки перед установкой. Но **текущий код сейчас не собирается**: после обновления Command Line Tools до 27.2 (7 ноября) компилятор не находит плагин `SwiftUIMacros`, нужный для `@State`. Установленная версия от 5 ноября работает, но выпустить исправление или обновление нельзя, пока сборка не починена.

## Находки

### 🟠 P1-1 · Проект не собирается на текущем тулчейне

> **Исправлено 2026-11-14** (не закоммичено): четыре `@State` заменены на `@StateObject` с обёрткой `Box`. Попутно найдено и исправлено второе: `build.sh` брал бинарник по старому пути `.build/arm64-apple-macosx/release/`, а Swift 6.4 кладёт его в `.build/out/Products/Release/` — скрипт молча упаковал бы сборку от 5 ноября.

**Что не так** — `error: external macro implementation type 'SwiftUIMacros.StateMacro' could not be found … plugin for module 'SwiftUIMacros' not found`. В SDK 27.2 `@State` стал макросом, а в Command Line Tools плагина нет (в `usr/lib/swift/host/plugins` только `ObservationMacros` и `SwiftMacros`). CLT обновлены 7 ноября, последняя удачная сборка — 5 ноября. Xcode не установлен.

**Последствие** — `install.sh` и `build.sh` падают; README обещает «Xcode не нужен», это больше не так. Любое исправление заблокировано.

**Исправление** — на выбор:
1. перенести четыре `@State` в `ObservableObject` с `@Published` (это не макрос) — остаётся сборка только с CLT;
2. поставить Xcode 27 и переключить `xcode-select` (предположительно плагин там есть — не проверено).

**Проверка** — `./scripts/build.sh` завершается «Собрано: …».

- тестовой цели: логика `ModeEngine` (очередь быстрых нажатий, повтор смены стола) проверяется только вручную через `--rapid-test`;
- доступности для VoiceOver (P2-4);
- способа удалить приложение: нет ни скрипта, ни раздела в README (приложение, оба домена настроек, элемент входа, сертификат в связке);
- актуального README (P3-1);
- проверки, что резервная копия действительно доехала: при недоступном сервере установка лишь печатает предупреждение, и недоставленные папки никто не досылает.
